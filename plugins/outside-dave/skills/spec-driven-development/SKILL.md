# Spec Driven Development

A spec is the source of truth about how a piece of software and its functions should behave and operate.

## The workflow

1. Spec creation or modification
2. Analysis and design
3. Implementation planning
4. Implementation
5. Review

## Prerequisites

For agentic development to be truly successful, the following need to be in place:

- Guard rails. This is the constitution: the coding rules. These are necessary.
- Architecture rules. These explain how the application should come together.
