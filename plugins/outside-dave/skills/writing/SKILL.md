# Writing

Before drafting, invoke the communication skill and apply its voice, grammar and final check. If it is unavailable, tell the user, then use its fallback: lead with the point, write short active sentences in plain language, use British or South African spelling and avoid em dashes.

Read only the reference that matches the output:

- Documentation, READMEs and wikis: [documentation guidance](references/documentation.md)
- Comments, docstrings, descriptions, commit messages and pull request text: [code-adjacent guidance](references/code-adjacent.md)
- Error messages and interface text: [interface copy guidance](references/interface-copy.md)

When a task spans categories, read each matching reference.
