# Spec driven development

This version targets web development as the specs are geared towards maintaining websites. 

## Requirements

- Constitutions. These are coding rules and gaurd rails.
- Architecture. This is how your application is structured, what exists and where, This should stay up to date.

## Workflow

1. Define your architecture.
2. Define your coding rules.
  a. As much as possible, these must be done via linters.
  b. Patterns and conventions must be stated.
  c. How to test your application should be defined.
